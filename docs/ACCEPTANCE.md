## 需要合法资源才能完成的 P0/P1 项

1. 用真实 `PINBALL.DAT`、本地提取的 `PB_MSGFT.BIN` 和全部引用 WAV 启动，确认完整原版台面、计分栏、文本和音效。
2. 蓄力约 0.3s / 1s / 2s 发射，观察不同发射力度；验证左右挡板同时输入、松开复位；暂停后恢复球速度/状态不突变。
3. 至少完整进行一局，验证各 bumper/ramp/gate/drain/挡板碰撞，任务状态、军衔增长和结算。对照同资源的原始上游版本，不能仅以源码哈希替代实测。
4. 触发高分姓名输入、保存、刷新并重新导入，确认原版前五名和本机最高分恢复；重开不清空最高分。
5. 实听 WAV 音效；可选 MIDI+合法音色库；音量 0 完全静音、恢复音量，首次触摸解锁声音。
6. 在真机完成以下 P3 清单。只有实际结果和设备版本登记后才能声明 iPhone Safari / 安卓 Chrome 支持验收通过。
