Space Cadet 运行说明

这是原版逆向工程引擎的 WASM 移植。游戏数据需要由你合法提供；此站点不分发商业游戏资源。

  1. 选择你自己的 Windows XP Pinball 安装目录中的 PINBALL.DAT 和全部 .WAV。页面按 DAT 列出缺失的音效，可分多次选择。
  2. 从你自己的 PINBALL.EXE 导出 FONT / PB_MSGFT 原始资源为 PB_MSGFT.BIN。源码包包含 scripts/extract-font.py，依赖 pefile==2024.8.26。不要从未知下载站获取游戏资源。
  3. 音乐可选：原版 PINBALL.MID 和你可合法使用的 GM.SF2。没有音色库时保留 WAV 音效。
  4. 点击启动后，左右半屏分别控制挡板，可同时按住。独立发射按钮按住蓄力、松开发射；电脑使用 Z、/、空格，方向键左右也可控制挡板。F3 暂停，F2 重开，X / . / ↑ 晃台。

文件只在当前浏览器页面内存读取，不上传。刷新后重新选择文件。最高分、原版排行榜和音量存入本机 localStorage；清除网站数据会删除记录。首次触摸游戏解锁声音。

切后台自动暂停；返回后点继续。全屏 API 不可用的 iPhone 会使用页面内沉浸布局，系统栏可能保留。完整 600×416 游戏画面保留黑边，等比例显示。
